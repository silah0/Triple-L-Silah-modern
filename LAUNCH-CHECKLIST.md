- [ ] Enable static hosting (for example, GitHub Pages).
- [ ] Replace `YOUR-DOMAIN` in the Open Graph and Twitter image metadata with the final public image URL.
- [ ] Test the public link in a private browser window.
- [ ] Test desktop, tablet, and mobile layouts.
- [ ] Check category filters, counts, search, product details, mobile navigation, and all section links.
